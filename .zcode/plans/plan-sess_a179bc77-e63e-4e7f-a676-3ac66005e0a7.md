## 需求（澄清后）

悬浮窗**展开后**，面板里**每张笔记卡片**左滑：未归档卡片→归档；已归档卡片→删除（硬删除：库行+录音文件）。动画速度/交互风格与悬浮窗既有节奏保持一致。

主 App 日记页已有同构交互：`SwipeDismissCard`（lib/widgets/swipe_dismiss_card.dart）——左滑拖跟手、右侧露圆圈进度图标（diary_tab.dart:3293 传 `icon: isArchived ? Icons.delete : Icons.archive`）、过阈值（0.5 屏宽）或快甩（velocity<-300）触发。悬浮窗直接复用这套视觉语言。

## 关键冲突与解法

1. **卡片宽度不匹配**：SwipeDismissCard 写死 `SizedBox(width: screenWidth)`（全宽卡片用）；悬浮窗卡片是右对齐自适应宽度，直接套会拉宽破坏胶囊造型 → **给组件加可选参数 `fullWidth`（默认 true 不改现行为）**，false 时 Stack 贴合子宽，图标揭示区就在卡片右侧原位。
2. **手势竞技场冲突**：面板层已有「右滑收起」的水平拖拽（overlay_home.dart:1523）；卡片内再包一层水平拖拽后，**卡片上的右滑会被卡片赢得竞技场，收起失效** → 组件加可选回调 `onSwipeRight`（右向累计位移过 `edgeSwipeThreshold`(4dp) 松手触发），卡片把右滑转发给 `_collapse()`，保住「任意位置右滑收起」。
3. **动画节奏**：组件加可选时长/曲线参数（默认维持现值 250ms）。悬浮窗传：回弹 = `animationDuration`(200ms)+easeOutCubic（卡片级动画节奏）、划出 = `panelSlideDuration`(240ms)+easeInCubic（与面板收起滑出同款加速推出感）。

## 改动内容

### 1. `lib/widgets/swipe_dismiss_card.dart`（向后兼容泛化）
- 新可选参数：`fullWidth`(默认 true)、`springDuration`/`springCurve`/`dismissDuration`/`dismissCurve`（默认现值）、`enabled`(默认 true，false 不参与手势)、`onSwipeRight`(默认 null)。
- 默认行为逐字节不变，主 App 日记页零影响。

### 2. `lib/overlay/overlay_home.dart`
- **itemBuilder（:1658 OverlayDiaryCard）外包 SwipeDismissCard**：`fullWidth: false`、`icon: isArchived ? Icons.delete : Icons.archive`、`onDismissed: () => _onCardSwipeDismissed(diary)`、`onSwipeRight: _collapse`、`enabled: _editingDiaryId == null`（编辑态滑动只收键盘，与面板手势降级规则一致）。圆圈危险色用主题 `ext.dangerAccent`（实现时确认 overlay 引擎主题有该槽位，缺则近似色）。
- **新增 `_onCardSwipeDismissed(diary)`**：
  - 防抖（`_archivingIds`/`_deletingIds`）+ 现场清理：从 `_diaries` 乐观移除该条、清 `_expandedIds`/`_deleteConfirmIds`/`_tagPickingIds` 的该 id；正在编辑该卡则丢弃编辑。
  - 未归档 → 归档分支：`_vibrate()` + `_dataClient.archiveDiary(id)` + `DiarySyncBridge.bump()` + 250ms(`archiveRefreshDelay`) 后静默刷新——卡片划走，稍后置灰划线出现在「已归档」分隔线下。
  - 已归档 → 删除分支：把 `_onCardDelete`（:557）的确认分支抽成 `_deleteDiaryConfirmed(diary)`（停播→vibrateTick→`deleteDiary`(删行+删音频)→bump→reload），两击确认与左滑共用执行体。
  - try/catch 失败回滚 reload（同 `_toggleArchive` 模式）。
- 胶囊把手、展开/收起编排、语音速记、复选框归档等一律不动。

### 3. 常量
不新增：时长/曲线在调用点传 `OverlayConstants.animationDuration` / `panelSlideDuration` 并注释同源性；`edgeSwipeThreshold` 注释补引用方。

- 现有 overlay 测试不受影响；`flutter analyze` 零 error + 全量测试过（基线 173 例）。
