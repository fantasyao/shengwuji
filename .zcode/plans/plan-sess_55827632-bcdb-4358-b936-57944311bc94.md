# Pro 授权体系 + 新拟物主题 Pro 化 实施方案

## 需求与已拍板决策

- 新拟物主题设为 Pro；Pro 解锁改为「付款 → 邮件(fantasyao@foxmail.com)发付款截图+安卓 ID → 开发者回授权码 → App 输入解锁」，替换现有「自觉点按钮解锁」。
- 授权码：**16 字符短码（XXXX-XXXX-XXXX-XXXX）+ 藏盐哈希校验**（用户知情拍板，放弃公钥验签；开源仓库+藏盐只能防 grep/小白，防不了认真逆向——代码注释与文档如实标注此边界）。
- 点 Pro 弹窗告知流程；**「先试用 7 天」**按钮全量解锁所有 Pro 功能（晴空蓝/新拟物主题、图标包、悬浮窗、音量键手势）；到期后门禁拦截，**下次启动时 Pro 主题自动回退默认青**。
- 未解锁按音量键触发悬浮窗/悬浮窗录音时：**原录音胶囊位置（312×84 窗口）显示「暂未解锁，无法使用」提示胶囊** 3 秒自动消失，替代现有 Toast。

## 改动内容（按提交拆分）

### Commit 1：授权基础设施
- **`tools/license/gen_license.py`**（纯标准库 hashlib/secrets/base64，`uv run` 运行）：`keygen` 生成 64hex 藏盐 secret 存 `tools/license/secret.txt`（**加 .gitignore**）；`issue <androidId>` 出码：`salt(2B随机)+SHA256(secret‖androidId‖salt)[0:8]` 共 10B → base32 → 16 字符带 `-` 分组；`verify` 子命令交叉自校。
- **`MainActivity.kt`**：channel `com.shengwuji.app/app` 加 `getAndroidId`（`Settings.Secure.ANDROID_ID`）与 `verifyLicense(code)`（normalize→base32 解码→取 salt→重算 SHA256→恒时比较；secret 常量拆成多段异或掩码拼接，避免开源仓库 grep 一眼可见）。
- **`lib/utils/license_service.dart`**：channel 包装 + `normalizeLicenseCode`/格式预校验纯函数（可单测）。
- **`lib/utils/pro_gate.dart` 扩展**：新 key `pro_trial_deadline_ms`（0=未试用）；`isProActive()` = `is_pro_unlocked ‖ now<deadline`；`startTrial()`（仅 deadline==0 时可开，过期不可重试）；`isProActiveWithPrefs(prefs,{now})` 纯函数；`tryAccess` 改判 isProActive。所有时间参数默认真实时钟并补默认路径单测（ [[regression-test-default-path]] 教训）。

## 已知边界（如实声明）

- 开源仓库 + 藏盐哈希 = 防伪强度靠逆向门槛（用户已知情拍板）；release 目前 debug key 签名，APK 可重打包，本方案不解决重打包问题。
- ANDROID_ID 仅在输入授权码瞬间参与校验；恢复出厂/换机后需重新申请（预期行为）。
- 试用一次性，过期后「先试用」按钮不再出现。
